# Claude Code Skills

Colección personal de *skills* para [Claude Code](https://claude.com/claude-code).
51 skills organizadas por carpeta; cada una tiene su `SKILL.md` con el `name`,
la `description` (cuándo se activa) y las instrucciones.

## Uso

Copia la carpeta de la skill que quieras a tu directorio de skills:

```sh
cp -R skills/<nombre-skill> ~/.claude/skills/
```
